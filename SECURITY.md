# Security policy

This project is pre-1.0 and has no supported production release yet.

Please do not file public issues containing credentials, certificate private
keys, bearer tokens, secret payloads, or details that would enable access to a
live deployment. Report suspected vulnerabilities privately to the project
maintainers with a minimal reproduction and affected version/commit.

Do not rely on local AWS emulation as evidence that IAM, API Gateway mTLS,
Object Lock Compliance, or cross-account policies are correct in AWS.
